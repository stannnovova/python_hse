# Password Manager

Консольный менеджер паролей на Python с мастер-паролем, шифрованием записей и генератором надёжных паролей.

Проект выполнен в рамках лабораторной работы Б1.

## Возможности

- Создание и проверка мастер-пароля.
- Добавление, просмотр и удаление записей.
- Просмотр списка сервисов без раскрытия паролей.
- Повторное подтверждение мастер-пароля перед просмотром записи.
- Генерация случайных паролей.
- Скрытый ввод паролей.
- Хранение зашифрованных данных в JSON.

## Установка и запуск

**Требования:** Python 3.14 и [uv](https://docs.astral.sh/uv/).

Перейдите в папку `lab_1` и установите зависимости:

```bash
uv sync --dev
```

Запуск программы:

```bash
uv run python main.py
```

При первом запуске программа предложит создать мастер-пароль. При последующих запусках потребуется его подтверждение.

Дополнительные команды:

| Команда                            | Назначение                    |
| ---------------------------------- | ----------------------------- |
| `uv run python main.py --init`     | Создать хранилище             |
| `uv run python main.py --unlock`   | Разблокировать хранилище      |
| `uv run python main.py --generate` | Сгенерировать надёжный пароль |
| `uv run python main.py --help`     | Показать справку              |

После разблокировки доступно интерактивное меню: добавление записи, просмотр списка сервисов, получение пароля, удаление записи и выход.

## Безопасность

Для защиты данных используются:

- **PBKDF2-HMAC-SHA256** — получение проверочного хэша и ключа шифрования из мастер-пароля.
- **Случайная соль (16 байт)** — защита от атак с предварительно вычисленными хэшами.
- **700500 итераций PBKDF2** — усложнение перебора мастер-паролей.
- **AES-256-GCM** — аутентифицированное шифрование логинов и паролей.
- **secrets** — криптографически стойкая генерация случайных значений.

Мастер-пароль не сохраняется в открытом виде. Данные хранилища записываются в `data/vault.json`, который исключён из Git.

**Важно:** восстановление забытого мастер-пароля не предусмотрено. Проект предназначен для учебных целей.

## Структура проекта

```text
lab_1/
├── password_logic/
│   ├── __init__.py
│   ├── crypto_logic.py
│   ├── password_manager.py
│   └── interface.py
├── tests/
│   ├── test_password_manager.py
│   ├── test_generator.py
│   └── test_interface.py
├── data/
├── main.py
├── pyproject.toml
└── uv.lock
```

- `main.py` — точка входа и обработка CLI-аргументов.
- `interface.py` — взаимодействие с пользователем.
- `password_manager.py` — управление хранилищем.
- `crypto_logic.py` — хэширование, получение ключей и шифрование.
- `tests/` — автоматические тесты.

## Тестирование и проверка кода

Запуск тестов:

```bash
uv run python -m pytest -v
```

Проверка качества и форматирования:

```bash
uv run ruff check password_logic main.py
uv run ruff format --check password_logic main.py
```

Статический анализ типов:

```bash
uv run mypy --strict password_logic main.py
```

В репозитории настроен **GitHub Actions CI**, который автоматически запускает тесты, Ruff и mypy при отправке изменений.
